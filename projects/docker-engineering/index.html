Docker Engineering

A practical Docker implementation by Rakesh Randeria covering container image creation, Docker Hub publishing and GitHub Actions automation.

Overview

This project demonstrates a simple container workflow using Docker and GitHub. Source code is maintained publicly on GitHub, while the built container image is published to Docker Hub through an automated GitHub Actions workflow.

GitHub Source Docker Hub Image

What It Demonstrates

  • Docker image creation
  • Container execution
  • Public image publishing
  • Docker Hub registry usage
  • GitHub Actions CI/CD
  • Secure repository secrets
  • Automated publishing from GitHub to Docker Hub

Architecture

GitHub Source ↓ GitHub Actions ↓ Docker Image Build ↓ Docker Hub
