# Docker Engineering A practical Docker implementation by Rakesh Randeria covering container image creation, Docker Hub publishing and GitHub Actions automation. ## Overview This project demonstrates a simple container workflow using Docker and GitHub. The source code is maintained publicly on GitHub, while the built container image is published to Docker Hub through an automated GitHub Actions workflow. ## Project Links - GitHub source: https://github.com/rakeshranderia/docker-engineering - Docker Hub image: https://hub.docker.com/r/rakeshranderia/docker-hello ## What It Demonstrates - Docker image creation - container execution - public image publishing - Docker Hub registry usage - GitHub Actions CI/CD - secure use of repository secrets - automated publishing from GitHub to Docker Hub ## Architecture GitHub source code → GitHub Actions → Docker image build → Docker Hub publishing ## Author Rakesh Randeria Technology Executive | Strategy | Transformation | Cybersecurity | AI & Digital Enablement | IT Operations & Resilience
