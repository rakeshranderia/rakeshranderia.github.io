Publishing Model

Website for curation. GitHub for depth.

The website surfaces the most useful material and explains how it fits together. GitHub remains the canonical source for reusable frameworks, technical detail and version history. Articles and external publishing are curated separately through the Writing page.

New material is added when it is genuinely reusable; the goal is a useful library, not the largest possible catalogue.
